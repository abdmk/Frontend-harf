# «عين» — فيديو تعريفي (Motion Graphics)

فيديو 1920×1080، 30 إطاراً في الثانية، ‎~32.6 ثانية، بلا صوت (جاهز لموسيقى).

- **الاتجاه البصري:** مرجع إعلان «LangEase». منه أُخذت الكلمات التي تظهر من الضبابية، والعنصر الذي يتوسّط الجملة، ونفق الواجهات، والانتقال من شريط التقدّم إلى «تم» والقصاصات، والبطاقات التي تنزلق ثم تُعزل، والزرّ الذي ينفجر نجمة، والملخّص بثلاث كلمات، ثم الشعار.
- **وظيفة المنتج:** من فيديو حرف القديم. الخطوات: رفع الصورة، التحليل، «تم العثور على ٣ خطوط مطابقة»، ثم بطاقات بنسب تطابق 95٪ و60٪ و30٪.
- **اللغة البصرية:** هوية حرف من مصادر الموقع نفسها، دون أي نسخ مكرّر:
  - الألوان والظلال ومنحنيات الحركة: من `src/design-system/tokens.css`.
  - الخطوط: Graphik Arabic وخطوط المكتبة من `src/assets/fonts`.
  - الأيقونات: من `src/components/ui/icons/icons.generated.ts`.
  - الشعار: من `src/components/shared/harf-logo.tsx`.

## التوليد

```bash
node promo/ayn/render.mjs                    # الفيديو النهائي → promo/ayn/out/ayn.mp4
node promo/ayn/render.mjs --preview          # معاينة سريعة (960px، 15fps)
node promo/ayn/render.mjs --from 9 --to 15   # مقطع
node promo/ayn/render.mjs --stills 3.2,13.5  # صور ثابتة PNG
```

- يحتاج إلى Playwright (Chromium) وffmpeg مع libx264.
- يُلتقط الفيديو بـ30 إطاراً في الثانية مباشرة. ضبابية الحركة مرسومة داخل المشاهد نفسها (الكلمات والانتقالات). لم نستعمل دمج الإطارات (`--blend`) لأنه يترك صوراً مزدوجة على العدّاد والبطاقات المنزلقة.
- يتوقّف التوليد إن لم يُحمَّل أي خط مطلوب، فلا يخرج إطار بخط بديل.

## البنية

| الملف         | الدور                                                                             |
| ------------- | --------------------------------------------------------------------------------- |
| `index.html`  | المسرح 1920×1080، ورموز التصميم، وأنماط مكوّنات الموقع (البطاقة، الزرّ، الترويسة) |
| `timeline.js` | `render(t)`: كل إطار دالة نقية في الزمن، والمشاهد السبعة                          |
| `render.mjs`  | خادم محلي، والتحقّق من الخطوط، والتقاط الإطارات، والترميز                         |

لتعديل التوقيت يكفي تغيير أرقام `P(t, a, b)` في دالة المشهد المعنيّ.

| 5.0       | واجهة الرفع تنفتح                  | woosh                               |

| 20.0      | قائمة النتائج                      | woosh                               |

إضافة موسيقى (مع تلاشٍ في آخر ثانية):

```bash
ffmpeg -i promo/ayn/out/ayn.mp4 -i music.mp3 -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k \
  -af "afade=t=out:st=31.6:d=1" -shortest promo/ayn/out/ayn-music.mp4
```

## ملاحظات قبل النشر

- **عبارة «الذكاء الاصطناعي»:** يستعملها الفيديو كما طُلب. أما «عين» الحالية في الموقع فتطابق الأشكال بصرياً، فالأفضل نشر الفيديو مع محرّك الذكاء الاصطناعي الفعلي أو بعده.
- **ترخيص الخطوط في الفيديو:** Graphik Arabic، وكذلك غروب وقمرة وزين وليون، خطوط تجارية. يجب التأكد من أن تراخيصها تغطّي الاستخدام في فيديو إعلاني، لا الويب فقط، أو استبدالها بخطوط OFL.
