# «عين» — نسخة القزحية

فكرة مستقلّة عن النسخة الأولى (`promo/ayn`)، مبنية على الموقع وهويته البصرية وحدهما، بلا مرجع خارجي.

## الفكرة

**«ع» حرفٌ قبل أن تكون أداة، وشكلها عين.** تُروى القصة على أرضية الحبر، وهي الوضع الليلي الحقيقي للموقع (رموز ‎`.dark` في `tokens.css`)، وبأحمر حرف:

1. **«عين»:** الكلمة تُرسم بمخطّطها الحقيقي (أميري)، ثم تدخل الكاميرا تجويف «ع».
2. **القزحية:** نرى جداراً من الخطوط العربية في الحياة (لافتات وأغلفة وشعارات) مكتوبة بخطوط المكتبة نفسها. تركّز العين على «حكاية» وتلتقطها، ثم «رُفعت الصورة إلى عين».
3. **التفكيك:** حروف «حكاية» تنفصل، ويقيس الذكاء الاصطناعي كل حرف: إطاره، وعرضه بوحدات الخط، ونقاط منحناه.
4. **القرص:** القزحية تعود قرصاً عليه أسماء خطوط حرف. يدور ثم يتباطأ، والخط المارّ بالمؤشّر يظهر تحت البصمة مع نسبة التشابه، حتى يقفل على **Qomra Arabic** بنسبة 97٪.
5. **صفحة العيّنة:** الخط المكتشف كما تعرضه مكتبة حرف، مع شارة التطابق والترخيص والأبجدية، وزرّي «اختر الترخيص» و«افتحه في مختبر الخط».
6. **الجفن:** القزحية تنغلق حتى تصير نقطة حمراء، والنقطة تكبر فتصير رمز حرف (وهو دائرة حمراء أصلاً)، ثم الشعار والرابط.

## التوليد

```bash
node promo/render.mjs --comp ayn-iris                       # 1080p60
node promo/render.mjs --comp ayn-iris --format vertical     # طولي 9:16
node promo/render.mjs --comp ayn-iris --scale 2             # 4K
node promo/render.mjs --comp ayn-iris --stills 9.9,15.4     # صور ثابتة
```

- `glyphs.json`: الكلمات والخطوط التي تُستخرج مخطّطاتها («عين» بأميري، و«حكاية» بأحد عشر خطاً).
- `../shared/engine.js`: محرّك الحركة المشترك (المنحنيات، الأسطر الحركية، الأيقونات، التنسيقان).
